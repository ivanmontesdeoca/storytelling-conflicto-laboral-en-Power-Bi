Se utiliza un data set sobre conflictos laborales en el sector de la mensajería urbana con el objetivo de comparar la conflictividad entre repartidores tradicionales y repartidores de platafromas.
Se analiza la cantidad de conflictivos entre los años 2006-2023, y la principal demanda, accion de protesta y organizaciones que impulsa el descontento. 
A su vez, se analiza cómo evoluciona temporal y espacialmente estos patrones de conflicto. 
Finalmente, se compara la conflictividad laboral en ambos sectores hayando que la conflictividad es mayor entre trabajadores de plataformas y prevalecen los reclamos por seguridad e la vía publica.
